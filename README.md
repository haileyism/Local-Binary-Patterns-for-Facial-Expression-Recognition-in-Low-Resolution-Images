## Overview

The **PixelPercept SVM Architecture** is a novel approach to facial expression recognition, specifically designed to enhance accuracy in low-resolution images. This project leverages **Local Binary Patterns (LBP)** for effective feature extraction and employs **Support Vector Machines (SVM)** for robust classification.

## Motivation

Accurately interpreting facial expressions is crucial for advancements in **human-computer interaction, healthcare, and affective computing**. Low-resolution imagery poses significant challenges due to the loss of fine details essential for expression analysis. This project addresses these challenges by introducing a method that captures essential texture features, thereby improving recognition accuracy.

## Methodology

The approach consists of the following key steps:

1. **Face Detection and Alignment:**  
   - Utilizing OpenCV's **Haar cascades** for efficient face detection.  
   - Using **Dlib's shape predictor** for precise facial alignment.

2. **Feature Extraction:**  
   - Applying **Local Binary Patterns (LBP)** to capture texture details that are resilient to variations in illumination and scale.

3. **Classification:**  
   - Implementing a **Support Vector Machine (SVM)** with a linear kernel to classify the extracted features into distinct facial expressions.

## Results

Preliminary results demonstrate the effectiveness of the **PixelPercept SVM Architecture** in recognizing facial expressions from low-resolution images. The integration of **LBP and SVM** shows promise for **real-time applications** and **complex, dynamic environments**.
